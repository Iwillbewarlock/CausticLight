# CausticLight 계획 (A안)

물가의 벽과 천장에 물빛(물결을 지나 모인 빛의 그물 무늬)이 일렁이게 하는 스카이림 SE 모드.
물빛 무늬 판 + 그 앞의 보이지 않는 작은 조명 + 둘을 조절하는 SKSE 플러그인으로 이루어진다.

## 무엇이 들어가나

| 부품 | 하는 일 |
|---|---|
| 무늬 그림 3벌 (잔잔 / 보통 / 거침) | 각 64장면, 이음새 없이 이어지고 끊김 없이 반복된다. `tools/gen.cjs` 가 만든다 |
| 무늬 판 모델 (NIF) | 벽 앞 1~2 유닛에 붙는 판. 세 벌을 겹쳐 두고 섞는다. 가장자리는 서서히 투명해진다 |
| 작은 조명 | 그림자 없음, 반경 작음. 물빛 색으로 일렁여서 벽의 채집 재료, NPC, 플레이어에게도 빛이 닿게 한다 |
| 게임 데이터 (ESP, ESL) | 판과 조명의 "원본" 두 개만 담는다. 셀을 직접 고치지 않는다 |
| SKSE 플러그인 | 아래 판단을 해서 판과 조명을 조절하고, 배치 목록(JSON)을 읽어 셀이 열릴 때 판과 조명을 놓는다 |

## 플러그인이 판단하는 것

1. **얼마나 출렁이나**: 날씨의 바람과 비, 근처 물에 들어간 모든 존재(플레이어, NPC, 동료, 생물), 장소별 기본값
2. **얼마나 밝고 무슨 색이냐**: 바깥은 해와 달(시간, 흐림), 안은 근처 광원(횃불, 화로 등)의 색과 거리. 빛이 없으면 꺼진다

## 순서

1. 무늬 판 모델: 게임 기본 파일(`defaultwaterripples.nif`)을 본으로 삼는다. 본을 읽고 다시 써서 한 바이트도 다르지 않음을 확인한 다음에만 고친다.
2. 무늬 그림: 64장면을 큰 그림 한 장(8×8)에 모은다. 칸 경계에서 옆 장면이 번져 보이지 않게 칸마다 여백을 둔다.
3. 게임 데이터(ESP)
4. SKSE 플러그인
5. 배치 목록 한 곳 + 게임 안 확인 순서표
6. **오프라인에서 먼저 보여 줄 것**: 완성된 판 모델에 무늬를 입힌 그림
7. **게임 안 확인 한 번**: 무늬 넘기기 재생, 날씨 따라 속도, 광원 따라 밝기와 색, 벽 물건 일렁임, 생물이 물에 들어갈 때

## 최적화 (구상 단계부터 지킨다)

| 항목 | 정한 것 | 이유 |
|---|---|---|
| 무늬 그림 메모리 | 세 벌 합쳐 약 16MB, 모든 판이 함께 쓴다 | 판을 몇 개 놓든 메모리는 한 번만 든다. 4096 해상도도 시험했는데 눈에 띄게 낫지 않고 4배를 먹어서 2048로 되돌렸다 |
| 더 줄이는 안 (검토 후 버림) | ① 한 채널 형식(BC4) + 색 조견표: 실제로 도는 Community Shaders 셰이더를 읽어 보니 조견표는 초록 채널을 읽고, 판의 색 값을 조견표의 줄 번호로 써 버린다. 무늬도 안 나오고 플러그인이 색을 입힐 수도 없다. ② 투명도 없는 절반 크기 형식(BC1): 원본과의 오차를 재 보니 화질 점수가 44에서 33으로 떨어지고, 선 가장자리에 네모 얼룩이 생긴다 | 아끼는 양(8MB)에 비해 잃는 것이 크다. 지금 형식(BC7)을 유지한다 |
| 그리는 양 | 판 하나에 세 층이 있지만 한 번에 **최대 두 층만** 그린다. 비중이 0인 층은 숨긴다 | 투명한 판은 겹칠수록 비싸다 |
| 모델 크기 | 층마다 삼각형 256개 | 아주 적다. 가장자리를 부드럽게 흐리는 데 필요한 만큼만 |
| 거리 | 약 43m(3000유닛) 밖에서는 판을 흐려서 끄고 조명도 끈다 | 멀리서는 보이지도 않는 것에 비용을 쓰지 않는다 |
| 조명 | 그림자 없음, 작은 반경 | 그림자 조명은 비싸고 자리가 8개뿐이다 |
| 플러그인 | 날씨와 시간은 1초에 한 번. 물에 들어간 존재 확인은 1초에 네 번, 근처 것만. 광원 목록은 셀이 열릴 때 한 번만. 매 프레임 하는 일은 가까운 조명의 일렁임뿐 | 게임 한 프레임에 쓰는 시간을 거의 0으로 둔다. 판이 하나도 없으면 아무 일도 하지 않는다 |

## 알려 둔 한계

- **처음에는 평평한 벽만** 다룬다(돌 건물, 드웨머 유적, 우물, 수조). 울퉁불퉁한 동굴 벽에서는 평평한 판이 바위에 파묻히거나 떠 보인다. 동굴은 나중 단계(벽 모양을 딴 판, 또는 B안).
- 광원과 물 사이를 벽이 가로막는지는 따지지 않는다. 배치할 때 빛이 실제로 닿는 자리를 고른다.
- 벽의 물건은 무늬 선이 아니라 일렁이는 빛을 받는다.
